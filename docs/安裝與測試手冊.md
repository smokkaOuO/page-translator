# 網頁翻譯小幫手 0.2.0 安裝與測試手冊

適用對象：第一次安裝並設定此 Chrome 擴充功能的使用者。

## 一、功能總覽

| 功能 | 說明 | 是否需要金鑰 |
|---|---|---|
| 整頁翻譯 | 翻譯整個網頁，可雙語對照，快捷鍵 `Alt+T` | 否（使用 Chrome 內建） |
| 滑鼠停留翻譯 | 滑鼠停在文字上一段時間後顯示翻譯，延遲可在選項頁調整 | 否 |
| 反白翻譯 | 反白文字後翻譯，快捷鍵 `Alt+S` | 否 |
| Google Cloud 翻譯 | 內建引擎不支援時的備援，或指定優先使用 | 需要 Google Cloud Translation API 金鑰 |
| 深度查詞 | 音標、情境例句、近義詞辨析 | 需要 Gemini API 金鑰 |

最低需求：Chrome 138 以上。

## 二、安裝擴充功能

1. 下載本 repo（GitHub 頁面「Code → Download ZIP」後解壓縮，或使用 `git clone`），找到其中的 `extension` 資料夾，裡面應有 `manifest.json`。
2. 在 Chrome 網址列輸入 `chrome://extensions`。
3. 開啟右上角「**開發人員模式**」。
4. 點左上角「**載入未封裝項目**」，選擇 `extension` 資料夾。
5. 列表出現「網頁翻譯小幫手」即安裝完成。卡片上的 ID 應為：
   `mhojjifbdpkeodikfnjacjopdidbjojg`
   此 ID 是固定的，不論從哪個資料夾載入、重新安裝或更新版本都不會改變。
6. 點工具列的拼圖圖示，把此擴充功能「釘選」，方便使用。

### 為什麼要用「載入未封裝項目」？
一般版 Chrome（Windows、macOS）只允許安裝 Chrome 線上應用程式商店上架的 .crx 封裝檔，自行封裝的 .crx 會被停用或拒絕安裝。因此本擴充功能以未封裝資料夾的方式提供。

### 更新到新版本
- **保留設定**：把新版 `extension` 資料夾的檔案覆蓋到原本的資料夾，再到 `chrome://extensions` 按此擴充功能的「重新載入」圖示。
- **移除後重新安裝**：選項頁的設定與金鑰會被清空，需重新貼上。ID 不變，Google Cloud 的網站限制不用改。

## 三、最快上手：只用 Chrome 內建（免費、不需金鑰）

1. 開啟選項頁（見第四節）。
2. 「翻譯引擎 → 引擎順序」選「**只用 Chrome 內建（免費、離線）**」。
3. 按頁面最下方「**儲存**」。
4. 到任一外文網頁，按 `Alt+T` 翻譯整頁，再按一次還原。
5. 反白一段文字，按 `Alt+S` 翻譯選取內容。

首次使用時 Chrome 可能需要下載語言模型，請稍候。

## 四、開啟選項頁

擇一：
- 點工具列圖示，在彈出視窗按「開啟設定」。
- `chrome://extensions` → 此擴充功能「詳細資料」→「擴充功能選項」。

選項頁可調整：翻譯單位（整句／單字）、停留延遲、反白翻譯、雙語樣式、排除網站、快取，以及 Google 每月字數上限（預設 450000，0 為不限制）。

## 五、設定 Google Cloud Translation 金鑰（選用）

### 5.1 建立專案並啟用帳單
1. 開啟 [Google Cloud Console](https://console.cloud.google.com/)，建立或選擇專案。
2. 到「帳單」，把專案連結到帳單帳戶。Translation API 必須啟用帳單，但有每月免費額度。
3. 若出現「無法啟用計費功能：已達可啟用計費功能的專案數量上限」：
   - 到[帳單頁面](https://console.cloud.google.com/billing) → 選帳戶 → 「帳戶管理」，在「專案」表格找出不用的專案，按「⋮」→「停用帳單功能」。
   - 或點對話框的「要求提高配額」申請提高上限。
   - 完成後回到原專案重新「設定帳單帳戶」。

### 5.2 啟用 API
「API 和服務 → 程式庫」搜尋 **Cloud Translation API**，按「啟用」。

### 5.3 建立 API 金鑰
1. 「API 和服務 → 憑證 → 建立憑證 → API 金鑰」。
2. **應用程式限制**：選「**網站**」，新增下面這一行（直接複製，不要加任何符號）：
   `chrome-extension://mhojjifbdpkeodikfnjacjopdidbjojg/*`
   若欄位不接受此格式，先選「無」，待測試成功後再回頭加。
   若你安裝的是自行修改過 manifest 的版本，請以 `chrome://extensions` 顯示的 ID 為準；填寫時不要加上 `< >` 角括號，否則測試金鑰會出現「Permission denied on the service」。
3. **API 限制**：選「限制金鑰」，只勾 **Cloud Translation API**。
4. 按「建立」，複製金鑰（`AIza...` 開頭）。設定最多需 5 分鐘生效。

> 注意：從 Google AI Studio 申請的 Gemini 金鑰不能當作此金鑰使用，否則會出現「API keys are not supported by this API」。

### 5.4 貼到選項頁並測試
1. 選項頁「翻譯引擎」→「Google Cloud Translation API 金鑰」欄位，貼上金鑰（可按眼睛圖示確認）。
2. 按「**測試金鑰**」，顯示成功才算通過。
3. 「引擎順序」選含 Google 的選項：
   - Chrome 內建優先，不支援時改用 Google
   - Google 優先，失敗時改用 Chrome 內建
   - 只用 Google Cloud
4. 按「**儲存**」。
5. 在「測試翻譯」輸入文字，確認有譯文。「本月已用字數」應開始累計。

## 六、設定深度查詞（Gemini，選用）

深度查詞使用的是 **Gemini 金鑰**，與第五節的 Google Cloud Translation 金鑰是兩把不同的金鑰，不能混用：

| 金鑰 | 用途 | 取得位置 | 貼到選項頁的位置 |
|---|---|---|---|
| Google Cloud Translation | 翻譯引擎 | Google Cloud Console | 「翻譯引擎」區塊 |
| Gemini | 深度查詞 | Google AI Studio（免費） | 「深度查詞 (Gemini)」區塊 |

### 6.1 取得 Gemini 金鑰
1. 開啟 [Google AI Studio 金鑰頁面](https://aistudio.google.com/apikey)，以 Google 帳號登入。選項頁也有連結「前往 Google AI Studio 免費取得金鑰」。
2. 按「建立 API 金鑰」，選擇專案（沒有的話讓它自動建立）。
3. 複製產生的金鑰。用量計算在你自己的帳號上，免費額度有限制。

### 6.2 貼到選項頁並測試
1. 開啟選項頁（第四節），捲動到「**深度查詞 (Gemini)**」區塊。
2. 勾選「**啟用深度查詞**」。
3. 在「Gemini API 金鑰」欄位貼上金鑰。
4. 「模型」欄位通常維持預設即可；若測試失敗或查詞出錯，可改成 AI Studio 目前提供的模型名稱。
5. 按該區塊的「**測試金鑰**」，顯示「金鑰可用」。
6. 按頁面最下方「**儲存**」。
7. 重新開啟彈出視窗（工具列圖示），確認查詞輸入欄可以輸入。

### 6.3 輸入欄是灰色、不能輸入？
彈出視窗的查詞輸入框與「查詢」按鈕，在尚未設定 Gemini 金鑰時會被停用，視窗內會顯示「查詞需要 Gemini 金鑰：設定」。這與翻譯引擎是否成功無關。處理方式：

1. 依 6.1、6.2 完成 Gemini 金鑰設定，並確認已勾選「啟用深度查詞」與已儲存。
2. 若仍是灰色，到 `chrome://extensions` 按此擴充功能的重新載入圖示，再開啟彈出視窗。
3. 只想翻譯、不用查詞的話，可以忽略這個欄位，不影響翻譯功能。

### 使用方式
- **網頁上**：反白單字，點「深度查詞」。
- **彈出視窗**：點工具列圖示，使用查詞面板，三種模式：

| 模式 | 輸入 | 範例 |
|---|---|---|
| 單字 | 英文單字或片語 | `commit`、`look forward to` |
| 音譯 | 用中文或注音打出讀音 | 「斯波ㄍㄟ替」→ spaghetti |
| 描述 | 描述想找的字的意思 | 「很想睡但睡不著」 |

結果可按「朗讀」發音，按「返回建議」回到候選清單。

## 八、疑難排解

| 現象 | 原因與處理 |
|---|---|
| API keys are not supported by this API | 使用了 Gemini 或 AI Studio 的金鑰，或專案未啟用 Cloud Translation API。改用 Cloud Console 建立的金鑰，並確認已啟用 API 與帳單 |
| Permission denied on the service | 網站限制與擴充功能 ID 不符：確認填的是 `chrome-extension://mhojjifbdpkeodikfnjacjopdidbjojg/*`，沒有多餘的 `< >` 角括號或空白。也請確認專案帳單仍啟用、Cloud Translation API 仍啟用 |
| 金鑰無效或沒有權限 | 金鑰貼錯、API 限制未包含 Cloud Translation API，或設定尚未生效（等 5 分鐘） |
| 驗證失敗 (HTTP 429) 或額度用盡 | 超過配額。調整「Google 每月字數上限」，或改回 Chrome 內建 |
| 無法啟用計費功能 | 帳單帳戶專案數已達上限，見 5.1 |
| 查詞需要 Gemini 金鑰／查詞輸入欄反灰 | 尚未設定 Gemini 金鑰或未啟用深度查詞，見第六節（6.3） |
| Gemini 金鑰測試失敗 | 確認貼的是 AI Studio 產生的金鑰，不是 Cloud Translation 的金鑰，且沒有多餘空白 |
| 查詞失敗 | 檢查 Gemini 金鑰與模型名稱，再按「測試金鑰」 |
| 背景服務沒有回應，請重新載入擴充功能 | 到 `chrome://extensions` 按此擴充功能的重新載入圖示 |
| 輸入太長了 | 縮短查詞輸入 |
| 找不到符合的詞 | 換個說法再試 |
| 快捷鍵無反應 | 到 `chrome://extensions/shortcuts` 檢查是否衝突，可自行修改 |
| 某些網站無法翻譯 | 檢查選項頁「排除網站」清單；Chrome 內建頁面（如 `chrome://`）不支援擴充功能 |

## 九、安全提醒

- API 金鑰等同密碼，不要貼到公開場合或截圖分享。已外流的金鑰請到 Cloud Console 刪除並重新建立。
- 一定要設定 API 限制；有條件時再加網站限制。
- 建議在 Google Cloud 設定預算提醒，並保留選項頁的每月字數上限，避免意外費用。
